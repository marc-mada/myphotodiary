# Images

Screenshots referenced from the [Installation Guide](../Installation%20Guide.md)
and the [User's Manual](../User's%20Manual.md), plus the project logo used by
the top-level README.

Naming convention:

- `desktop-*.png` — desktop UI screenshots (Gallery, Search, Admin, popups).
- `mobile-*.jpg` — mobile UI screenshots, taken on a real phone.
- `install-*.png` — installation/deployment screenshots, if any are added.
- `icons/` — the viewer's control-bar icons, as shown in the User's Manual
  §2.2: the `.png` ones are copies of `frontend/public/legacy/`, the `.svg`
  ones are exported from the icons drawn in `frontend/src/gallery/ImageViewer.jsx` (`hd.svg`: the HD button, off state)
  — update them here too if those change.
